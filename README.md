# Mess Hall 45 — Official Website

Official website for **Mess Hall 45**, located in Fayetteville, Arkansas.

## About
Mess Hall 45 serves handcrafted toasted submarine sandwiches, burgers, comfort food, and sides while honoring our nation's military service members and first responders.

## Features
- Full interactive and categorized food menu with current pricing.
- Interactive category quick-jump navigation pills.
- Dynamic hero food photography slideshow with subtle transitions.
- "Wall of Honor" marquee honoring local and national service heroes.
- Responsive mobile & desktop presentation.
- One-touch phone ordering: `(479) 332-4051`.

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
